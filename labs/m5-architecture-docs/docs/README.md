## 从哪读起（30 分钟 onboarding 路径）

1. **10 分钟**：[4+1 视图图集](views/views-template.md) —— 先看逻辑视图（模块划分），再看物理视图（部署拓扑）。
2. **10 分钟**：[质量属性场景](quality-scenarios.md) —— 系统的非功能承诺，每条都可验证。
3. **10 分钟**：[ADR 索引](adr/) —— 挑最近 3 份已接受的 ADR，理解"关键决策为什么这么做"。

## 文档目录

| 目录 | 内容 | 更新时机 |
|---|---|---|
| `views/` | 4+1 视图图集（mermaid 源文件） | 结构变化的同一个 PR 里更新 |
| `quality-scenarios.md` | 质量属性场景清单（六要素表格） | 新增非功能承诺时 |
| `adr/` | 架构决策记录（不可修改，只可被新 ADR 取代） | 每个重要决策一份 |
| `reviews/` | 架构评审纪要（含风险清单与行动项） | 每次评审后归档 |
