AI 全栈架构师之路 · 自学教程包

零基础 → 架构师的一条实战路径：服务端 × 分布式 × AI Infra × SRE × 企业级 Agent × FDE 交付。原题「从小白到 AI 架构师」，现统一为「AI 全栈架构师之路」。

一条连贯的实战学习路径：从服务端筑基出发，经过架构演进、数据密集型系统（DDIA）[1]、分布式架构（凤凰架构）[2]与平台工程、架构师方法论（软考体系），进入 AI 开发基础、AI Infra、SRE 与可靠性工程、AI Agent 企业工程化，最终以 AI FDE 交付实战收官。全程由一个贯穿项目 「RetailHub → DataAgent」（零售经营数据平台 → 多租户经营分析 Agent 平台）串起，每卷末尾都有「本卷实战」演进任务，学做结合。

先读 总纲：AI 全栈架构师之路：十阶段学习地图、知识源融合逻辑、项目演进时间线、学习方法论与各阶段最低通过标准。

里程碑 对应卷目 跑起来能看到什么
m1-monolith 卷01 FastAPI 单体：5000 订单分页、GMV 汇总 API

使用建议

  1. 按阶段顺序推进，不要跳读：每卷导语都会交代"项目当前状态"，跳卷会丢失上下文。
  2. 每卷的「本卷实战」是必选动作：建议学做时间比 4:6；验收标准全部打勾再进下一卷。
  3. 阶段六、九即原《企业级 Agent 工程架构》教程内容，已有基础的读者可从任一阶段切入，但请先完成该阶段之前各卷的"最低通过标准"自测（见总纲）。
  4. mermaid 图在支持 mermaid 的 Markdown 阅读器（VS Code、Obsidian、Typora、GitHub）中可直接渲染；也可以打开 site/ 目录下的教程网站版本（npm run dev 本地预览）。

说明：本教程包为原创自学材料，融合了 DDIA、《凤凰架构》、软考知识体系等公开知识源的学习路径设计，不包含这些著作的原文内容；其中"极客时间"相关部分基于公开课程大纲扩展，非官方课程正文。
